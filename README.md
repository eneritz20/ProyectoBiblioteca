##  Descripción del proyecto
Este proyecto consiste en una **aplicación de consola en Java** diseñada para gestionar una **biblioteca multimedia**, cumpliendo los requisitos de la *Práctica 1 – Git y repaso de Programación*.  
El objetivo es reforzar los contenidos de Programación y trabajar correctamente con Git y GitHub durante todo el desarrollo.

La aplicación permite gestionar **usuarios**, **recursos multimedia** (libros, películas y videojuegos) y un sistema completo de **préstamos y devoluciones**, manteniendo la información mediante **ficheros CSV**.



## Funcionalidades principales

###  Gestión de usuarios
- Crear usuarios  
- Listar usuarios  
- Buscar usuarios por ID  
- Modificar usuarios  
- Eliminar usuarios  
- Control de IDs duplicados  

###  Gestión de recursos
- Crear recursos (Libro, Película, Videojuego)  
- Listar recursos  
- Buscar recursos por ID o por título  
- Modificar recursos  
- Eliminar recursos  
- Consultar disponibilidad (prestado / disponible)  

###  Préstamos y devoluciones
- Registrar un préstamo  
- Comprobar existencia de usuario y recurso  
- Impedir préstamo si el recurso ya está prestado  
- Registrar devolución  
- Actualizar estado del recurso automáticamente  

###  Consultas


###  Persistencia en ficheros
- Carga automática de datos al iniciar  
- Guardado automático al cerrar  
- Formato CSV  
- Control de errores:  
  - Ficheros inexistentes  
  - Datos corruptos  
  - Tipos incorrectos  
  - IDs duplicados  
  - Préstamos imposibles
